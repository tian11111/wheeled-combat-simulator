# 真机遥测物理标定闭环

## Goal

建立从真机试验数据到模拟器参数、误差报告和保真度声明的可复现闭环，使项目能够用证据回答摩擦、碰撞、堵转和登台预测的可信范围，而不是继续依赖手工假设。

## Background And Confirmed Facts

- 当前规则、回放和场地布局已经验证，但 `fidelity.json` 仍把摩擦、碰撞、堵转标为 `uncalibrated`，登台标为 `hand_drawn`。
- 当前内核使用简化的确定性 2D 模型：`VehicleProfile.LatFrictionK`、`AngDamping`、`SimParameters.BlockMuK`、`CollisionRestitution`、`StallSpeed`，以及 `PhysicsWorld` 内部的固定登台速度/角度门槛。
- `Scenario.Parameters` 已能覆盖大部分全局参数；车辆参数随 `VehicleProfile` 进入场景与回放，因此标定结果可以在不破坏确定性契约的前提下驱动 CLI 和 Godot。
- 遗留原型 `D:/project/robocup/robot-simulator/sim_calibrate.js` 已实现离线拟合、样本下限、RMSE、SHA-256、建议 patch 和选择性更新 fidelity；可迁移其已验证算法，但不能继续把 Node 脚本作为新项目的产品入口。
- 遗留工具支持 `lateral_coast`、`angular_coast`、`block_push`、`collision`、`stall` 和 `mount` 六类试验；其中 `mount` 只计数，不足以拟合或验证登台模型。
- 当前仓库没有真实遥测文件，只有遗留拟合器的合成自测数据；因此仓库本身无法证明任何物理子系统已经标定。

## Requirements

### R1. 版本化遥测契约

定义版本化 JSON 遥测格式，统一使用米、秒、弧度和 SI 派生单位。契约至少覆盖侧滑衰减、自由旋转衰减、能量块滑行、撞墙/双车碰撞、堵转正反标签和登台成败轨迹，并在入口一次性完成类型、单位、时间戳、试验元数据和样本完整性校验。

### R2. 可复现离线拟合

在 .NET CLI 中提供离线标定命令，迁移并验证遗留拟合算法，输出样本数、参数估计、误差指标、置信或稳定性信息、输入 SHA-256、工具/协议版本和可应用的 `VehicleProfile` / `Scenario.Parameters` patch。工具不得直接修改权威代码常量或运行中的比赛。

### R3. 训练/验证分离

每个子系统必须支持按 trial 划分拟合集与留出验证集。保真度结论必须基于未参与拟合的试验误差；仅在合成自测上恢复预设参数不能升级 fidelity。

### R4. 登台可验证性

将登台门槛从 `PhysicsWorld` 私有固定常量提升为显式、可版本化的参数，并定义按入射速度、角度、方向和载荷重复试验的成功概率/混淆矩阵验证。若现有确定性门槛无法达到约定误差目标，报告模型不足，不得通过过拟合单次轨迹宣称已标定。

### R5. 安全应用与回归

标定结果以新场景/profile 文件应用，保留官方默认场景和旧回放的逐位兼容。任何参数应用都必须通过 130 项现有测试、固定 seed 回放、参数边界校验和标定留出集回归。

### R6. 可审计保真度升级

只有满足每类最低试验数量、质量门槛和留出误差目标时，才能生成建议的 `fidelity.json` 更新；更新必须引用数据哈希、报告路径、试验日期、车辆/场地条件和局限。缺数据或误差超标时保持原状态。

## Acceptance Criteria

- [ ] 无效单位、非递增时间、缺失位姿/速度、未知试验类型和样本不足均返回明确错误，且不产生可应用 patch。
- [ ] 遗留合成数据的等价夹具能在容差内恢复 `latFrictionK=8`、`angDamping=3`、`BLOCK_MU_K=0.45`、`COLLISION_RESTITUTION=0.33` 和位于正反堵转样本之间的 `STALL_SPEED`。
- [ ] 同一输入多次运行产生相同参数、数据哈希和确定性报告内容；生成时间等非决定字段不参与内容指纹。
- [ ] 至少一个标定 profile/场景可被 CLI 和 Godot 共用，且旧 seed-42 回放在未选择该 profile 时保持逐位一致。
- [ ] 报告分别展示拟合集和留出集指标；合成自测、训练误差或单次试验不能单独触发 fidelity 升级。
- [ ] 登台验证覆盖成功与失败样本，并按速度/角度分桶输出预测混淆矩阵；达不到目标时保持 `mount` 为未标定或手绘状态。
- [ ] `dotnet build`、`dotnet test`、CLI replay-check、Godot parity-check、标定器合成回归和真实/样例遥测端到端检查全部通过。

## Out Of Scope

- 不在没有证据前重写为完整四轮接触、悬挂、轮胎侧偏或 3D 权威刚体模型。
- 不自动控制真车、采集摄像头/IMU 或搭建硬件通信协议；本任务消费导出的离线遥测。
- 不标定灰度传感器、红外距离或视觉识别；这些应按各自数据契约单独立项。
- 不用一次参数扫描或仿真胜率宣称真机比赛表现。

## Open Decision

- 是否已有可用于本任务的真机遥测，决定验收范围是否包含“首轮真实参数与留出验证报告”；如果没有，本任务只能交付工具链、实验模板和合成/样例数据验证，`fidelity.json` 必须继续保持未标定。
