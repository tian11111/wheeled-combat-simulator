# 能量块布局可配置: 数量可调 + 增益/减益类型

## Goal

用户(2026-10-04): "加上能调整能量块数量，增益减益都要有"。
让能量块的数量可调（不再固定 2 增益 + 1 减益），且增益/减益两种类型都可放置——
入口是桌面布局编辑器；场景 JSON 与内核同步支持任意组合。

## Requirements

- R1 桌面布局编辑器(E 模式)：
  - 可添加能量块（新增默认增益块，落点不与既有块重叠）；
  - 可删除选中的能量块；
  - 可切换选中能量块的类型（增益 ↔ 减益）；
  - 三个操作都进撤销/重做；HUD 提示与按键帮助同步更新。
- R2 场景/内核支持任意布局组合：
  - `Scenario.Blocks` 允许 0..12 个块，增益/减益任意混合；
  - 0 块（纯对抗）合法；>12 块给出明确校验错误。
- R3 观测与 3D 位姿支持多个减益块：
  - `ObjectSet.Debuffs` 列表按块索引顺序暴露全部减益块；
  - `ObjectSet.Debuff` 保持 = 第一个减益块（向后兼容既有控制器/RL 环境）；
  - `PhysicsPoses.Debuffs` 同样补列表，`Debuff` 保持 = 第一个。
- R4 桌面渲染支持多个减益块：SnapshotView/ArenaVisualizer 按列表渲染全部块。
- R5 计分语义不变：增益块上台 +3 推块方；减益块上台 +6 给对手；每个块独立计分。
- R6 回归安全：
  - 默认官方布局（2 增益 + 1 减益）行为逐位不变，seed-42 回放 parity 保持；
  - 回放门禁只比分/事件/结束原因/tick 数，观测新增字段不破坏既有回放；
  - RL 环境(gym_env)观测消费保持兼容（仍读 Debuff=first），本轮不重训。

## Acceptance Criteria

- [ ] R1: 编辑器 B 添加 / K 切换类型 / Delete 删除，undo/redo 覆盖，保存-重载往返一致
- [ ] R2: 协议校验测试覆盖 0 块合法、13 块报错
- [ ] R3: 引擎测试覆盖多减益块观测（Debuffs.Count==N，Debuff==first）与各自独立计分
- [ ] R4: SnapshotView 帧包含全部减益块视觉
- [ ] R6: `dotnet test` 全绿 + seed-42 parity fixture 不变
- [ ] 桌面冒烟（无人值守编辑器流程）覆盖 加块→切类型→删块 一轮

## Notes

- 编辑器是唯一交互入口；CLI/JSON 手编场景本就支持列表，本次只补数量校验。
- 不改计分规则、不做 RL 重训、不动设置页（布局归布局编辑器管）。
