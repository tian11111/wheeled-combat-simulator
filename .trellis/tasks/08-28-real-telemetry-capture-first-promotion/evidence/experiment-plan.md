## 试验矩阵

### 1-2. lateral_coast / angular_coast(横向摩擦 / 角阻尼)

- 初速档:v ∈ {0.4, 0.8, 1.2} m/s(建议,覆盖 fitter 的衰减对区间);角速度档:ω ∈ {±2, ±4} rad/s。
- 每档 ≥1 个 fit trial + ≥1 个 holdout trial(硬门禁:各集 ≥2 有效 trial)。
- 操作:给定速度稳定后**零指令**滑行至停止;帧率 ≥20 Hz(≤0.05 s)。
- 安全:空旷 2 m 净空;滑行方向远离围栏。
- 预估:每 trial ~5 s + 复位,全部 ~20 min。

### 3. block_push(方块摩擦)

- 初速 0.5 / 1.0 / 1.5 / 2.0 m/s 各 ≥2 次(1 次 fit + 1 次 holdout);推块后立即停车不再触碰。
- 记录块轨迹 `{t, block{x,y}}`(车端视觉/人工测距按 field-mapping 决定)。
- 预估:~20 min。

### 4. collision(恢复系数)

- 撞墙:正对与 30°/60° 斜撞,速度 ≥0.5 m/s;记录撞击前后 `{vx,vy}` 与法线方向。
- 每组(正对/斜撞)≥3 次有效入射(法向分量 >0.05 且反向);fit/holdout 分离。
- 预估:~20 min。

### 5. stall(堵转阈值)

- 顶墙/顶固定障碍,指令从低速到高速扫描;每档记录实测速度 + `stalled` 标签。
- fit ≥6、holdout ≥6,正(堵转)/负(未堵转)标签齐全。
- 预估:~15 min。

### 6. mount(登台门控验证,不拟合)

- 速度桶 × 角度桶矩阵(见 design.md §3):至少覆盖 3 个桶、每桶 ≥2 次,合计 holdout ≥12 且成功/失败都有。
- 建议:vn ∈ {0.25, 0.4, 0.6, 0.9} m/s × 入射角 ∈ {0°, 12°, 18°, 30°} 交叉选点。
- 记录每次 `{vn, vt, outcome}`;失败(卡沿/弹回)也是有效数据,必须记录。
- 预估:~30 min。

## 当场记录义务

- 每个原始文件写入 `telemetry/data/<vehicle>-<date>/raw-hash.tsv`(文件名 + SHA-256 + 对应 trial ID + fit/holdout)。
- 任何中断/重试/判废当场在 trial ID 后标注,不得事后无痕修改。
