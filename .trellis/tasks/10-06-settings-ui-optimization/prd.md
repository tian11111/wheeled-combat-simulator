# 设置界面优化：复现/比赛场景页/交互统一/打磨

## Goal

把桌面设置界面从"能改"升级为"团队可复现、演示可操控"。主目标受众是**团队多人/复现场景**：配置能以单文件在成员间流转，复现所需参数（含 RL 训练配置）能随配置包一起导出导入；同时清掉代码审计（`research/settings-ui-audit.md`、`research/config-surface-gap.md`）发现的高/中严重度 UX 与交互缺陷，补齐"需要设置但只有命令行入口"的参数。

一次对齐（grill-me 四轮）已拍板：主目标=团队复现；范围=补参数/重排文案/视觉/交互四方面全动；dev 参数进折叠高级区；复现形态=配置包导出/导入 + 新建训练配置文件；任务粒度=本 task 内分四批；批次顺序=复现优先。

## Requirements

### 批1：复现基座（配置包导出/导入 + 训练配置文件）

- R1.1 设置页页脚提供"导出配置包…/导入配置包…"两个按钮，走文件对话框（单文件 `.json` bundle），不依赖 git。
- R1.2 配置包内容：schema 版本、主设置（`wushu-ring-settings.json` 全量）、外观模型配置（`robot-models.json` 全量）、场景文件（若 `--scenario-path`/当前场景为文件加载）或布局文件（`arena-layout-v1`）、训练配置文件。内嵌文件内容而非路径引用。
- R1.3 导入时校验 schema 版本；不匹配 → 明确中文报错并拒绝导入（**不做自动迁移**）。导入前给"将覆盖以下内容"的确认提示。
- R1.4 新建训练配置文件格式，`controllers/score_block_rl/train.py` 增加 `--config <json>`（字段=现有 CLI 参数，CLI 显式传参优先于配置文件）；配置包导出时收录当前训练配置（如有）。

### 批2：补缺失参数 UI（比赛/场景页 + 高级折叠区）

- R2.1 设置页新增"比赛/场景"标签页：
  - 物理后端选择：跟随场景（默认）/ legacy / mujoco v1 / mujoco v2；非"跟随"时覆盖场景 `physics.backend`/`physics.modelVersion`。
  - 场景文件选择（文件对话框 + 路径回显）。
  - 比赛时长（默认 120s）与随机种子输入；提供"换种子重开"操作（等价改 seed + F5 重置）。
- R2.2 设置页新增"高级/开发者"折叠分组（默认收起）：L1/L2/L3 legacy 接触扩展开关（默认全开=现行为）。
- R2.3 所有新增字段缺省值必须保持现状行为逐位不变（老配置文件无新字段时 = 跟随场景/默认全开）。

### 批3：交互统一（修复丢数据/冲突/生效链路）

- R3.1 `Vehicle`（车体+传感器覆盖）纳入 `MatchSettingsEqual`：改小车参数在实况中同样触发自动重置；修掉"仅改小车参数日志谎报显示设置已应用"。
- R3.2 切换传感器预设时保留当前未应用的通道编辑：从当前控件回填再重建通道行，而非从上次保存值回填。
- R3.3 能量块页"自定义能量块布局"开启时，若当前场景带 `layoutVersion`（布局编辑器产物），弹确认警告"将覆盖布局编辑器结果"，取消则不开启。
- R3.4 校验错误文案中文化（显示层映射，`Validate()` 保持结构化英文键不动）。
- R3.5 每个标签页页脚标注该页设置的生效时机（立即/下一场自动/需 F5）。
- R3.6 "恢复默认"同时重置外观模型区。

### 批4：打磨（重排/文案/视觉）

- R4.1 参数 tooltip 从内部键名换成中文说明（含影响方向与单位），覆盖 24 项仿真参数与各页控件。
- R4.2 去掉参数行重复单位显示（`Suffix` 与相邻 Label 二选一）。
- R3.5/R4.3 路径类输入（视觉证据包、CSV、外观模型路径、场景文件）接入文件选择器（复用 `LayoutEditor` 的 `FileDialog` 模式）。
- R4.4 设置窗尺寸改为自适应视口（含最小尺寸 + 外层滚动），修 uiScale 1.4/小窗口裁切。
- R4.5 `MakeOption` 改为按 id 取义（选项下标仅作 UI 顺序），消除加/删/换序错位隐患。
- R4.6 低优先级视觉项：全屏时禁用宽高输入；视觉源禁用路径框改隐藏（或保留但配占位说明）；硬编码文案与示例路径集中成常量。

## 明确不做（本轮拒绝项）

- 轮-地摩擦/solref/电池压降模型/原地转向补偿等**标定常量不进 UI**（改了会破坏回放身份/模型哈希；电池模型未标定）。
- 不做命名预设机制（传感器多套命名 profile、多套设置预设的保存/切换）——当前只有"预设+覆盖"。
- 不做配置包自动迁移（导入只接受匹配的 schema 版本）。
- `schemaVersion` 不暴露 UI；`--events/--stats/--out/--start-at`、capture/smoke/parity 旗标、`--robot-models`、`batch --parallelism` 保持 CLI。
- 场景 `vehicles[]` 几何/物理字段、`field` 几何、`tickSeconds` 不做 UI（场景 JSON 职责）。
- MBri 决策常量、fidelity.json、奖励常量保持代码。

## Acceptance Criteria

### 批1
- [ ] 导出：在任一台机器导出 `.json` 配置包；在另一台导入后，设置页各项、外观模型、场景/布局与导出机一致；导入含确认提示与版本校验（篡改 schemaVersion 后导入被拒并显示中文原因）。
- [ ] `train.py --config <json>` 与原纯 CLI 跑出的训练配置等价（CLI 显式参数覆盖配置文件字段）；配置包内嵌训练配置。
- [ ] 现有 `dotnet` 测试全绿；新增配置包序列化/导入校验单测。

### 批2
- [ ] "比赛/场景"页可切换物理后端并立即在下一场生效；"跟随场景"时行为与现在逐位一致。
- [ ] 种子输入 + "换种子重开"可复现出与 `--seed N` 启动一致的对局轨迹（同 seed 同布局）。
- [ ] 老设置文件（无新字段）加载不报错、行为不变（回归测试钉住默认值）。

### 批3
- [ ] 仅改小车参数点应用：实况中自动重置且日志正确描述；传感器预设切换不丢未应用编辑（手工用例 + 单测）。
- [ ] 开启自定义能量块布局覆盖布局编辑器场景前有确认弹窗，取消则保持布局编辑器结果。
- [ ] 校验错误在 UI 上为中文；每页页脚有生效时机标注；"恢复默认"后外观模型区回空。

### 批4
- [ ] 24 项仿真参数 tooltip 为中文说明；无重复单位；路径输入可弹文件对话框。
- [ ] 1280×720 + uiScale 1.4 下设置窗完整可见可操作（`--settings-smoke --capture` 截图目检，对照 `research/settings-ui-audit.md` §D）。
- [ ] `MakeOption` 消费端按 id 取义，相关页（控制器模式/视觉源/能量块落位/传感器预设）行为不变（现有测试全绿）。

### 整体
- [ ] 每批独立提交，批内先 `trellis-check` 再交付；批次顺序：批1 → 批2 → 批3 → 批4。
- [ ] 桌面实机目检按 `godot-qa-smoke-capture` 通道执行（注意：自定义参数必须放 `--` 分隔符之后）。
