# 实车记录复盘与场地数据对照

## 目标与范围

- 在 Godot 桌面仿真器中独立导入和复盘实车记录，重点对照灰度、红外、判断、安全事件、状态、视觉结果和电机指令。
- 兼容用户提供的历史十列巡台 CSV，并支持版本化 `real-match-v1` JSON；缺失字段明确显示未记录，不把模拟结果、推断位置或无时间戳文本冒充现场事实。
- 导入用户提供的灰度及铲下采样 CSV，显示原始曲线和统计；仅允许对用户确认静止的区间手动填写场局部坐标和车头朝向，单独保存和重开参考点并在场地图手动对照。
- 只修改仿真器；不修改树莓派程序，不录制摄像头、不承诺提供真车自动采集；保留现有比赛、设置、布局和模拟回放行为。
- 用户补充：复盘中需要看到 3D 擂台及车辆。仅当记录包含带时间戳、坐标及朝向的明确位姿时驱动车辆；旧巡台 CSV 没有位姿时必须提示未记录且不编造运动。合成位姿示例必须明确标注为演示数据。

## 验收标准

- [x] 十列巡台 CSV 按原始行顺序单步，重复时间戳稳定保序；空文件和格式错误可见说明，未记录的 FSM、视觉及电机字段不伪造。
- [x] 同名 `.log` 作为独立未同步文本查看，不将无时间戳事件绑定 CSV 时刻。
- [x] `real-match-v1` 示例支持按时间/原始顺序展示有明确来源的原始和处理读数、判断、状态、安全、视觉和电机事件；缺失值不自动补全。
- [x] 灰度/铲下 CSV 的曲线、统计、静止区间手工标注、参考点保存重载与场地图选择可用；无坐标、未确认静止的样本不生成点，不自动交换左右通道。
- [x] 完成纯逻辑测试、构建、实际 Godot 视觉/交互验证及原有模式回归；如受环境限制，按实际结果披露。
- [x] 支持有位姿记录的 3D 展示、按时间播放及单步定位；缺位姿时不显示虚构车辆或轨迹，数据来源和时间可见。
- [x] 验证实车复盘 3D 与数据时间线一致、不干扰原比赛/模拟回放；真实位姿记录尚未提供时只用合成示例做功能验证并明确披露。
