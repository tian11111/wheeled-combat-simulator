# RL v4 奖励归因单变量实验

## Goal

仅在原版 PPO 五训练 seed 基线不足 4/5 通过时，检验“边缘进展奖励缺少我方接触归因”是否影响真实得分；它是待验证假设，不预设修复有效。

## 前置报告与 Go / No-Go

- 必须有 `.trellis/tasks/archive/2026-09/09-27-rl-v4-split-guard/report.md` Go、`09-27-rl-v4-training-throughput/report.md` 下游策略 Go，以及 `09-27-rl-v4-split-multiseed/report.md` 完整负面基线（通过数 <4/5）。若原版达到 4/5，本任务标记条件未触发，不运行。
- 先用轨迹定义可审计的接触归因规则。若无法可靠区分我方、对手和自主运动，不训练变体，报告 No-Go 并停止本轮路线。
- 前三个固定训练 seed 中至少 2/3 通过开发集门槛，才补齐后两个；若少于 2/3，即使补齐也不可能达到 4/5，立即停止。
- 五个 seed 中至少 4/5 通过，才允许唯一候选冻结；否则报告负面结论并停止盲验。

## Requirements

- 仅改变边缘进展 shaping 的接触归因门控；reward 其它项/系数、11 维观测、PPO 配置、训练预算、物理、场景、FSM、开发 split 不变。
- 使用固定训练 RNG seed `20260927、20260928、20260929、20260930、20261001`，先 `20260927、20260928、20260929`，条件通过后补 `20260930、20261001`；每个至少 500k transitions。
- 每个模型在 `development_v4=9001–9020` 上与同场 FSM 比真实 `BlockScore`、我方 `Drop`、归因、fault，单模型门槛与原版相同。报告变体与原版逐 seed 配对差异，不以 reward 增长当成功。
- 接触规则与诊断 trace 在训练前冻结；训练/评测使用同一 reward 实现。最终集保持未打开。

## Acceptance Criteria

- [ ] 归因轨迹能解释我方接触、对手接触和无接触位移，且规则在训练前明确；无法做到时报告 No-Go、无变体训练。
- [ ] 仅边缘进展奖励门控改变；固定 seed 比较可复核，其他变量及所有模型身份/hash 记录完整。
- [ ] 3-seed 筛查和条件补齐遵守停止门槛；最终逐 seed 开发集结果完整，至少 4/5 才给冻结 Go。
- [ ] 裁判事件得分/掉台、归因和 fault 作为唯一门槛；reward/PPO loss 只作诊断。固定 seed 确定性、Gymnasium 接口、相关 Sim.Tests、旧回放及 `git diff --check` 通过。
- [ ] `report.md` 明确 Go/No-Go、与原版配对差异及是否允许进入 `blind-gate`；负面结果不得解锁盲验。
