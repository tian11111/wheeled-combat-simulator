# 设计：边缘进展奖励接触归因实验

## 假设与测量

现有 edge progress 依据目标块向边缘位移给 shaping，位移可能来自对手或碰撞余波。此项只把“由我方可归因的进展”作为奖励候选；是否改善真实得分由开发集裁判事件决定。先抽取含我方接触、对手接触、双方接触、无接触/惯性滑行的轨迹，定义时间窗口和争议事件处理；若数据不足或归因模糊，停止实验。

## 单变量边界

保持 reward v2 的分数、掉台、步数惩罚及 edge scale 系数不变；仅对 edge progress 增加归因门控。观测仍 11 维特权状态，PPO 超参数、动作、物理、规则、场景和 FSM 不变。训练和评估加载同一 reward 版本并记录代码/场景/配置哈希。归因诊断不得把未来信息或裁判真值注入 actor 观测。

## 两段训练与判定

先按 RNG seed `20260927–20260929` 各训练≥500k transitions，与同场 v4 开发集 FSM 比较。每个 seed 的通过条件为真实锁定目标 `BlockScore ≥ FSM`、我方 `Drop ≤ FSM`、可追溯且 fault=0。通过不足 2 个立即停止；否则再完成 `20260930–20261001`。最终至少 4/5 通过才按原版基线相同的开发集排序冻结唯一候选。

对照原版时逐训练 seed 列出 score/drop 差值和触发门控比例，不能把 reward 曲线变化解释为得分提高。v4 最终集在本任务全程封存。负面结果有效，但不解锁盲验。
