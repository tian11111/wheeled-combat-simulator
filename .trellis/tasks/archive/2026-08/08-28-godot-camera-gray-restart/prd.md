# Godot 相机交互、灰度与真实重启收尾

## Goal

补齐赛事控制台的镜头交互、场地灰度显示和真实重启语义。R 重启己方，T 重启对手；重启时对手增加 4 分，并保持回放与实时场景一致。

## Requirements

- 修复 Top 俯视模式，确保完整场地可见且镜头方向正确。
- 在非编辑器模式支持左键拖动视角和滚轮缩放；编辑器模式继续由布局编辑器处理鼠标拖拽。
- 修正灰度纹理坐标、材质受光和平台边界造成的错误对角线/灰度带；保留中心区域和“武”标识。
- 在 `src/Sim.Core` 实现真实机器人重启：目标机器人回到配置起点，清理运动、传感器和 FSM 瞬态；比赛计时、另一台机器人和场上方块保持正确。
- R/T 路由到对应机器人，重启事件明确记录，对手准确增加 4 分。
- 新重启命令支持回放和 Parity；旧 `restart:<role>:<kind>` 命令保持兼容。
- F5 从回放返回实时后重新同步场景、机器人、平台纹理和镜头。

## Constraints

- 不重新标定摩擦、碰撞、堵转或登台参数。
- 不把没有坐标的证据性质灰度 CSV 接入运行时，不重做视觉资产。
- 不引入新的 UI 框架或第二套场景变换系统。
- 核心状态和比赛规则留在 `src/Sim.Core`；Godot 只负责输入路由、镜头和显示。

## Out of Scope

- 物理模型、传感器模型、计分规则（重启对手 +4 除外）和已有比赛流程的整体重构。
- 通过修改旧 fixture 或基线分数来掩盖 Parity 差异。

## Acceptance Criteria

- [ ] Top 模式完整显示场地且方向正确；Overview、Follow、Top 切换后仍能正确聚焦。
- [ ] 非编辑器模式左键拖动和滚轮缩放可用；编辑器布局选择与拖拽行为不回归。
- [ ] 灰度方向符合场地坐标与 0–1000 语义，没有由 UV、采样或材质受光造成的错误对角线；中心标识与得分区正确。
- [ ] R/T 只在 Running 或 Paused 状态执行真实重启；目标机器人回到配置起点并清理瞬态，对手得分增加一次且仅增加 4 分。
- [ ] 重启保持比赛时钟、另一台机器人和场上方块；产生 `EventKind.Restart` 和 `restart_robot:<role>`，且可回放。
- [ ] 旧 `restart:<role>:<kind>` 回放命令行为保持不变。
- [ ] F5 从回放恢复实时模式后，模拟状态、可视化场景和镜头全部同步。
- [ ] `dotnet test --no-restore`、Godot Parity、编辑器 smoke 和真实渲染捕获验证通过。
