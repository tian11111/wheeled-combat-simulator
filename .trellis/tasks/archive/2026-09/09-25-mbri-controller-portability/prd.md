# MBri 真车控制器仿真接入契约与可观测性

## Goal

让持有 MBri `RobotController` 代码的使用者只依照公开协议、映射表和示例，就能把它接入 MuJoCo 官方场景完成一场 60 秒比赛，并准确知道哪些信号是仿真近似或特权真值。接入成功以协议稳定、时间正确、行为可追溯为准；比分与真机保真度另行评估。

## Confirmed facts and evidence

- 用户实测报告：现有 `D:/project/robocup/2026/MBri/sim_bridge.py` 以 `--controller-us` 跑通 60 秒、faults 0/0、比分 0:5。此记录尚无随任务保存的命令和原始日志，实施时须复现并存档。
- `docs/CONTROLLER_PROTOCOL.md` 已定义 0.05 s/tick、灰度 0–1000、红外约 0–1、动作 `v` m/s 与 `w` rad/s，但没有 MBri 侧的量纲/通道/时间适配表。MBri `config.py` 的 `GRAY_ADC_MAX=10000`；现有试验桥把灰度乘 10。
- 车端有六路低有效 GPIO 数字红外。当前官方 MuJoCo 场景使用默认 `Legacy14` profile，其距离红外和铲下通道不等价于这六路；可选 `WheeledCombat11` 有四路 Digital 通道，也不是一一映射。现有桥的阈值合成只能作为明确标记的仿真近似。
- 仿真 `objects` 是块的真值坐标和状态；MBri hunt 消费含 `detections`/`target` 的视觉字典。现有桥伪造 `confidence=0.9`，属于 privileged/oracle 输入，不能用于声称传感器等效或可部署真机的学习结论。
- MBri 左右轮命令到 m/s 的比例未标定；现有桥的 `1000≈0.55 m/s` 和轮距是猜测。`RobotController.update(..., now=)` 支持注入仿真时间，现有桥自行累加 0.05 s。
- 当前 CLI 在第一帧前调用 `Arm()`；外部动作使该角色进入 `Manual` 并跳过其内置 FSM，而计时、掉台、方块得分等裁判规则仍运行。`--events` 可输出事件。用户报告的“零我方事件”须按同一命令复现，区分没有触发该类事件与事件丢失；不得预设 Arm/裁判整体旁路。

## Requirements

- R1 在 `docs/CONTROLLER_PROTOCOL.md` 增加“移植真车控制器”章节：逐字段写明仿真与 MBri 的量程、单位、极性、方向、缺失值和来源；解释灰度 `0–1000 → 0–10000` 仅是接口量纲换算，不是已标定的物理等效；列出当前场景没有六路 GPIO IR 等价输入、`objects` 为特权真值、`v/w` 为物理单位。
- R2 提供最小可运行的 MBri JSONL 适配示例和固定测试观测。示例只做传感器格式、仿真时间、左右轮动作转换及协议回显；要求显式提供轮速比例与轮距，不内置猜测系数。近似 IR 和真值视觉只在显式 smoke/oracle 模式启用，并在运行元数据中标记；缺少必需的非近似输入时明确失败，不静默制造“有效”信号。
- R3 为轮速比例、轮距与正反方向写可执行标定步骤：在安全条件下分别以固定左右轮命令测直线位移、原地旋转角度和用时，记录命令/距离/角度/时间、拟合系数、适用车体与日期。未完成标定的运行只能标为协议 smoke，不能宣称运动保真或用于真机性能比较。
- R4 明确 `--controller-us` 的完整语义：比赛仍 Arm，外部角色首次接收动作后为 Manual，其内置 FSM 决策及 FSM 状态事件不再产生；对手 FSM 与裁判规则继续。区分协议 fault、控制器自身状态、裁判事件三类可观测信息；若复现时裁判事件缺失，再定位并补齐裁判级事件，不为调试而改变规则或旧事件含义。
- R5 示例从 `obs.t`/`tick` 注入 `RobotController.update(now=)`，不可用 `time.monotonic()` 或按处理速度累加墙钟；首帧、连续帧和跳帧/坏帧语义明确。stdout 仅写动作 JSONL 并回显 `requestId`，诊断写 stderr；遵守既有超时、坏行、零动作与 fault 契约。
- R6 在文档给出从准备 MBri checkout、配置标定参数、选择感知模式到运行/查看结果的完整命令；普通使用者不需阅读两边源码。示例不把 MBri 外部仓库纳入本仓库，也不更改官方场景、物理、裁判或 `fidelity.json`。

## Acceptance Criteria

- [x] AC1 映射表覆盖灰度、六路数字 IR、距离/铲下、视觉、左右轮、`v/w`、仿真时间，逐项标注“直接/换算/近似/缺失/特权真值”；给出可复核的标定表模板与未标定限制。
- [x] AC2 固定观测测试证明灰度量纲与边界、IR 极性/缺失处理、显式近似/真值模式、左右轮正反及限幅、`requestId` 回显和 `now=obs.t` 首帧行为；未知系数或未授权近似明确报错。
- [x] AC3 按文档命令用真实 `RobotController` 完成 60 秒官方 MuJoCo 场景 smoke，逐帧响应且 faults 0/0；保存命令、依赖/场景标识、适配模式、标定状态、最终比分及日志。此项不要求获胜，也不判定真机保真。
- [x] AC4 用可触发事件的固定场景/seed 验证 Arm、Manual 切换、该角色 FSM 事件缺席及裁判级事件仍可见；对“零我方事件”给出实测解释或修复证据。既有 JSONL 协议、回放与裁判结果不变。
- [x] AC5 headless 快跑和限速运行在相同 seed/动作输入下产出一致的控制器状态时间线；坏行/超时仍按零动作计 fault；定向测试与现有回归通过。

## Out of Scope

- 真机传感器/电机完成标定、车体物理保真晋升、自动生成六路 GPIO 真值、YOLO 模型训练或把仿真真值说成相机检测。
- 用 MBri 外部控制器替换默认 FSM；改比赛裁判规则、默认场景或旧回放字段。Gymnasium/PPO/快速 reset 归现有 `09-25-mujoco-score-rl-pilot` 任务。
