# RL v5 台沿风险奖励单变量实验

## Goal

验证假设：失败训练 seed 的掉台 22/24 发生在未接触目标块的窗口内（比赛提前终止 → 得分机会流失）；在 reward 中加入台沿风险项（基于我方台沿距离与向外逼近速度）能修复跨 seed 稳定性。预注册门槛 ≥4/5 通过才冻结唯一候选；`final_holdout_v4` 复审互斥性后作为唯一盲集。

## 背景与证据

- RL v4 轮：原版 PPO 3/5（负面基线）、归因门控变体 1/3（停止条款触发）。`archive/2026-09/09-27-*`。
- seed 行为诊断（`archive/2026-09/09-28-rl-v4-seed-behavior-diagnosis/report.md`）：失败 seed 掉台 10/12、12/12 发生在未接触目标块的 25 tick 内；比赛有效时长中位 255/276 tick vs 胜出 2,218；三者每千 tick 得分率相近（0.282/0.566/0.261），否定"推块效率差异"，支持"台沿行为导致提前终止"。

## 前置与门槛

- 直接继承 RL v4 终止状态：本轮为新预注册轮次，**不复用** `development_v4`（9001–9020，两轮选模已揭示）作门槛证据。
- 训练 RNG seed 沿用 `20260927、20260928、20260929、20260930、20261001`（与原版 3/5 基线同 seed 配对对照）。
- 训练 episode 池、PPO 配置、观测（11 维特权）、物理、FSM、场景、训练预算全部不变。

## Requirements

- R1 **单变量**：相对原版 reward v2 的唯一 delta 是台沿风险项；上一轮归因门控（提交 `9d519fb`）**回退**，Step() 恢复 v2 原样。
- R2 **风险项形式**（已确认）：`risk_t = −w · max(0, v_out_t − v0) · 1[dist_t < d0]`；
  `v_out_t = max(0, (dist_{t-1} − dist_t) / 0.05s)` 用机器人 `DistToNearestEdge` 差分（逼近台沿速度）；
  `d0 = 0.27 m`（FSM 守卫区宽）；`v0 = 0.2 m/s`（低于慢漂掉台中位 0.2268）。
- R3 **豁免（唯一红线）**：本 tick 我方接触目标块（目标块接触记录含 `us`）→ `risk_t = 0`；仅对手接触、双方接触、无接触均不豁免。policy 与 FSM 路径统一。
- R4 **参数冻结程序**：`w ∈ {0.005, 0.01, 0.02}`，在既有 60 段诊断轨迹（3 模型 × 20 场 policy）上回放，按判据选一并冻结：失败模型掉台前 25 tick 窗口的每 tick 平均罚值 ≥ 胜出模型全程每 tick 平均罚值的 3 倍，且任一单场累计 |risk| ≤ 1.0；判据无解 → 报告 No-Go、不训练。
- R5 **新开发集**：`development_v5 = 11001–11020` 注册进 `splits.py`（与训练池、全部历史集、已揭示集互斥）；`development_v4` 转为已揭示仅分析；守卫与 selftest 同步。
- R6 **盲集**：`final_holdout_v4`（10001–10050）复审互斥性与身份后继续作唯一盲集，候选冻结后仅运行一次。
- R7 **训练与停止**：三 seed（20260927/28/29）筛查，<2/3 停止不补齐；≥2/3 补 20260930/20261001；≥4/5 才冻结。
- R8 **防苟活条款**：逐 seed 报告掉台位置/时刻并与原版同 seed 对照；门槛只用配对真实裁判事件（锁定目标真实 `BlockScore` ≥ FSM、我方 `Drop` ≤ FSM、归因可追溯、fault=0），最终比分与 reward 仅作参考。
- R9 **身份与确定性**：训练/评测同构建并记录 CLI DLL 哈希；reward 变体记为 "reward v3 (v2 + edge risk term)"；固定 seed 确定性、Gymnasium 接口、受影响 Sim.Tests、旧回放、`git diff --check` 全绿；缺项明示不得判正向 Go。
