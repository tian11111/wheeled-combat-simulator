# 实车记录复盘契约

## 1. 范围与触发

桌面实车记录查看与 `sim-replay-v1`、物理标定和视觉证据分线。它只展示来源记录与人工参考，不创建模拟快照、不修改权威仿真、不将猜测位置称作真值。采集程序和摄像头录像不属于本功能。

## 2. 接口

- `Sim.GodotShell.RealMatchReviewData.LoadRecording(path)` 读取十列巡台 CSV 或 `real-match-v1` JSON；`LoadSeries(path)` 读取灰度/铲下采样 CSV。
- `MakeReference(series, name, startIndex, endIndex, x, y, heading)` 生成区间统计；`SaveReferences` / `LoadReferences` 写入和读取独立 `real-match-references-v1` 文件。具体 JSON 和列名见 `docs/REAL_MATCH_REVIEW.md`。
- Godot 复盘面板拥有独立导航状态，不调用 `MatchSession.LoadReplay` 或把实车数据注入内核。场地坐标是现有场局部米制，方向以弧度记录。

## 3. 合同

- 记录时间为单一来源相对秒，非递减；相同时间必须按原始顺序保留。旧巡台每一步是一条 CSV 记录，不保证是完整控制决策。
- 旧巡台缺失字段、空值以及新事件未提供的值显示未记录；原始通道名不得自动重排。无时间戳 `.log` 独立查看，不与 CSV 假同步。
- 可选 `pose` 事件只接受明确的 `role`、场局部 `x/y`、`heading` 和来源；3D 子视口独立于主比赛，按记录顺序展示对应角色最近一次位姿，未记录前隐藏角色，不插值或外推。场地与缺失高度仅为显示投影，不宣称实测；决策列表中的后续事件必须标明。
- 每个参考点必须由用户确认静止区间，人工填写位置和方向；保存源文件及闭区间索引和统计。文件名与曲线不能自动导出位置，未标注数据不能映射成轨迹或网格。
- 保存参考点先写同目录唯一临时文件，再替换目标；保存失败不能截断已有目标。曲线横轴按记录时间定位，降采样不得跨缺失数据连线，空通道统计显示未记录。

## 4. 校验与错误

| 输入 | 行为 |
| --- | --- |
| 空 CSV、无数据行或空 JSON events | 显示错误，不宣称导入成功 |
| 未支持表头、缺失必需字段、非有限或倒退时间 | 拒绝并显示原因 |
| 相同时间、可选字段空值 | 保留原始顺序和空值 |
| 未确认静止、索引非法、坐标或方向非有限 | 不创建参考点 |
| 新点超出当前场地范围 | 显示错误，不创建无法在地图上查看的点 |
| 导入的参考点超出当前场地范围 | 保留数据并提示数量，不在当前地图绘制 |
| 未知真实位置或无参考标注 | 不渲染虚构车体位置或轨迹 |
| 位姿缺少角色、坐标、朝向、来源或数值无效 | 拒绝记录并显示原因，不取默认值 |

## 5. 典型情况

- 完整 JSON 按实际提供的 sensor/decision/safety/state/vision/motor 事件查看，不从模拟器补值。
- 历史巡台 CSV 按记录行浏览；无 FSM 和左右电机的字段显示未记录。
- 仅凭“中轴”或“旋转两圈”文件名创建坐标点是不允许的。

## 6. 必要验证

- `RealMatchReviewTests` 覆盖旧 CSV 重复时间与空值、非法/空输入、新 JSON、参考区间统计和保存重开。
- 用实际样本只读验证 CSV 导入；在真实渲染器验证入口、单步、曲线、静止确认、参考点保存/点击、缩放及模态输入隔离。
- 用合成位姿验证两角色显示、无位姿隐藏、同时间顺序、前后单步不泄露未来位置、来源/高度说明及旧回放隔离；不能据此宣称真车位姿端到端通过。
- 检查完整 `Sim.Tests`、Godot parity、相机/编辑 smoke，保证既有模拟回放及操作不受影响；合成记录不构成真车端到端证据。

## 7. 错误与正确示例

错误：把巡台文字动作重算为左右电机命令，再用模拟位置给记录补轨迹。

正确：显示原动作与明确的未记录项，位置仅来自用户标注的静止参考点。
