# 实车记录复盘数据格式

此功能独立查看记录，不驱动模拟器。`godot/test-data/real-match-example.json` 是完整的**合成示例**，并非实车采集；当前功能不提供自动录制。

## 使用

1. 在比赛主界面选择“实车复盘”，通过“导入记录…”打开巡台 CSV 或 `real-match-v1` JSON。比赛或模拟回放在复盘期间挂起，主界面保留的比分属于原比赛，不是实车数据；关闭复盘后恢复原来的运行或暂停状态。播放、暂停、前后单步和时间轴只控制实车记录；旧 CSV 每步是一条记录，不等同于完整控制决策。
2. 记录包含 `pose` 时，比赛主场景显示对应车辆及其最近一次记录的位姿；右侧查看字段与事件，使用主相机查看场地。擂台使用当前场景，二维位姿的高度仅作场地投影；位姿来源和记录时刻显示在右侧。没有位姿的角色不显示，不按动作文字猜测运动。可打开 `godot/test-data/real-match-example.json` 并点击播放体验**合成**位姿示例。关闭复盘后恢复比赛界面和此前相机设置。
3. 同目录下同名 `.log` 会作为独立文本显示，也可手动打开；它没有可靠时间戳，不能与每条记录精确对齐。缺失的状态、视觉与电机数据不会补造。
4. 在“采样与参考点”页导入灰度或铲下采样 CSV，查看曲线和统计。曲线横轴按记录时间显示，缺测处断开；为提高显示效率会按行降采样。确认小车在某一区间静止后，填写从 **0** 开始的起止行索引、点名、场地局部 X/Y（米）与朝向（弧度），勾选“确认区间静止”并建立参考点。场地图原点在左下角；新点必须位于当前场地范围内。
5. 用“保存参考点…”另存为独立 JSON，之后可重开并点击场地图上的点查看详情；原采样文件不会被改写。浅色矩形为当前场地配置中的台沿，地图没有比赛真实轨迹；重开文件时超出当前场地的点会提示并保留，但不绘制。

文件中的前后左右名称保持原样；MBri 与现用程序的左右通道配置存在差异，物理对应关系需要实车核实。用户提供的旧数据存在短巡台片段，且部分样本可能来自模拟测试，不能自动认定为真实比赛。

## 文件格式

巡台 CSV 表头严格为 `t,front,rear,left,right,alert,on_stage,action,ir1,ir2`，采样 CSV 表头为 `t,front,rear,left,right` 或 `t,left,right,valid`。UTF-8，逗号分隔，支持单行引号转义；时间为非负有限秒且非递减，同时间保留原行顺序，时间必填，其他空字段表示未记录。采样数值必须有限，`valid` 也是可空数值。数据行不可省略。通道原名原样保留，不自动交换左右，不将巡台灰度称为原始 ADC。

JSON 顶层为 `{"format":"real-match-v1","events":[...]}`；事件数组至少包含一条记录。每条事件有有限非负数值 `time`（同一记录相对秒）、非空字符串 `type` 和对象 `values`。值为字符串、有限数值、布尔值或 null；不存在的字段保持不存在，null 表示未记录。事件按非递减时间提供，时间相等保序。示例涵盖 sensor、decision、state、safety、vision、motor；类型和字段由采集来源定义，来源必须明确，不能把不共同时钟的数据标作同步。同名 `.log` 无可靠时间戳，只能作为独立文本查看。

可选的 `pose` 事件必须在 `values` 中提供 `role`（`us` 或 `them`）、`x` 和 `y`（场局部坐标，米）、`heading`（弧度）以及非空 `source`（原样显示，例如 `measured` 或 `synthetic-example`）。坐标和朝向必须为有限数值；字段缺失或无效时导入失败。只有 `pose` 事件可提供记录位姿，不从动作或传感器推算。每个角色显示当前事件及之前最近的记录位姿，同时间按原事件顺序，不插值、不预测后续位姿；出现首个位姿前以及旧巡台 CSV 均为未记录。二维位姿不含高度，3D 显示高度是场地图形投影的展示假设，并非实测。示例中的所有位姿均为合成数据。

采样文件不包含精确位置。只有用户确认静止、选择包含两端的零基行索引，并手动填写场局部 X/Y（米）和朝向（弧度）后才生成参考点。参考点独立保存为 `real-match-references-v1` JSON：顶层 `format`、`references` 数组；每项含 `name`、`source`、`startIndex`、`endIndex`、`x`、`y`、`heading` 和 `stats`，其中各通道统计包含 `count`、`min`、`max`、`mean`。空通道 `count` 为 0，其余三个数字固定为 0 且无统计意义。来源路径与手填坐标原样保存，参考点不是轨迹或自动定位。
